# Predictive factors of acculturative stress among Latino/a/x/ and/or Hispanic college students
## Crystal Adote
This repository displays my thesis research where I examined the predictive factors of acculturative stress among Latino/a/x and/or Hispanic college students. This study is important because it sheds lights on the experiences that this community goes through and informs the general public. 

data/ = thesis dataset from survey 

code/ = analysis script from R 

output/ = figures

docs/ = thesis PDF
